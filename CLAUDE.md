## Maintaining CLAUDE.md Index Files

This repo uses a hierarchy of `CLAUDE.md` files for agent navigation.

- The root `CLAUDE.md` (this file) lists directories to two levels with a one-line description of each.
- Subdirectory `CLAUDE.md` files list the documents and key files within that directory.
- Deeper `CLAUDE.md` files may include relevant code information pertinent to the code they sit alongside (exported symbols, key interfaces, non-obvious behavior).
- Keep descriptions terse. One line per entry.
- Update the relevant `CLAUDE.md` when adding, removing, or renaming directories or documents.
